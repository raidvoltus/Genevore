# Recommended Texture Importer Presets (apply via AssetPostprocessor or manually)

## Environment (512)

- Max Size: 512
- Format (Android): ASTC 8×6 or ASTC 8×8
- Mipmaps: On
- Streaming Mipmaps: On (if large open world)

## Character / Module (1024)

- Max Size: 1024
- Format (Android): ASTC 6×6
- Mipmaps: On
- Read/Write: Off

## UI

- Max Size: 256
- Format: ASTC 6×6 or ETC2 RGBA
- Mipmaps: Off
